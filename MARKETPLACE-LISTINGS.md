# Marketplace Listings — CoinGecko MCP Server

## Listing 1: mcp.so

**Title:** CoinGecko MCP Server

**Category:** Finance & Crypto

**Description:**
MCP server for CoinGecko — free crypto market data API. Query prices, market caps, trending coins, search, historical data, and global stats through natural language. Works with Claude Desktop, Cursor, Windsurf, and any MCP-compatible client.

Features:
- Search cryptocurrencies by name or symbol
- Get current prices, market caps, 24h changes for any coin
- View top coins by market cap (top 10, 20, 50, 100)
- See trending coins in the last 24 hours
- Get detailed coin info (description, links, categories, genesis date)
- View historical price data (1d, 7d, 30d, 1y)
- Global crypto market stats (total MCap, BTC dominance)
- Compare multiple tokens side-by-side
- No API key required (CoinGecko free tier)
- Automatic rate limiting, retry on 429

**Tags:** coingecko, crypto, market-data, prices, bitcoin, ethereum, mcp, finance

**Installation:**
```bash
npx -y coingecko-mcp-server
```
